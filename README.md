- Data-Structures-and-Algorithms - 2026 - 2027

## Student Name: 
- Barizo, Julian Benedict D.R.

## Objectives:
The course aims to provide an understanding of analyzing algorithms and their complexity. It also allows the development of data structures including Abstract Data types, Linked Lists, Stacks, Queues, Trees, and Graphs using the C++ programming language. Additionally, use mathematical techniques to analyze the efficiency of the various algorithms presented, as well as the common operations on the data structures discussed. 

## CILO:

  1. Apply fundamental data structures and techniques to solve engineering-related problems through algorithm design.
  2. Design efficient algorithms and analyze their complexity.
  3. Build efficient algorithms based on selected data structures using good programming styles in C++
